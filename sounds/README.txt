Optional custom sounds for the overlay.

Put files here named:
  tick.mp3  (or tick.ogg / tick.wav)  - plays each time a symbol passes on the reel
  win.mp3   (or win.ogg / win.wav)    - plays when the reels land on a reward

If a file is missing, the overlay uses its built-in sound instead.
Refresh the OBS browser source after adding or changing a file.
Use a short tick sound (under 0.1 seconds), or the ticks will overlap at the start of a spin.
